# 사과 선별 데이터 요약

대상은 `sim-data/data/apple_A*.xlsx`이다. 판정 규칙은 `sim-data/templates/선별기준표.md`가 기준이다.

## 환경 주의

- 이 PC의 `python`은 Windows Store 스텁이라 종료 코드 49로 실패한다. Python을 쓰지 말고 PowerShell로 처리한다.
- `.xlsx`는 zip이다. 문자열이 인라인으로 저장되어 `sharedStrings.xml`이 없으므로 `xl/worksheets/sheet1.xml`을 직접 읽는다.
- 원본 엑셀은 수정하지 않는다. 결과는 새 파일로 `docs/`에 저장한다.

## 절차

1. **요약 실행.** 아래 스크립트를 실행하면 5~7단계에 쓸 수치가 한 번에 나온다.

   ```powershell
   powershell -File .claude/skills/data-report/scripts/summarize-apple.ps1 `
     -Path sim-data/data/apple_A07.xlsx `
     -CrosstabOut docs/사과_불량사유_위치별.xlsx
   ```

   `-CrosstabOut`은 교차표가 필요할 때만 준다.

2. **집계 항목.** 행 수와 날짜, 등급(상품/불량), 불량사유별 개수, 품종별·위치별 상품 비율, 무게·지름·당도·중심거리의 최소·최대·평균.

3. **기준표 재판정.** 멍 → 벌레 → 무게 250 이상 → 당도 11 이상 순서로 처음 걸린 사유 하나로 판정한다. 모든 행의 `불량사유`와 `등급`이 엑셀 값과 같아야 한다(불일치 0건). 다르면 요약을 내기 전에 먼저 보고한다.

4. **사유별 합계 검증.** 불량 사유(`없음` 제외)의 합이 `등급`이 불량인 행 수와 같은지 본다. 불량인데 사유가 `없음`인 행, 상품인데 사유가 있는 행이 없어야 한다.

5. **열 분류.** 아래 기준으로 나눠 설명한다.
   - 수치형: `중심거리`, `무게`, `지름`, `당도`
   - 이진 플래그(0/1): `멍`, `벌레`
   - 범주형: `위치`, `품종`, `불량사유`, `등급`
   - 시간형: `날짜`(보통 값이 하나뿐이라 사실상 상수)
   - 식별자: `사과번호`
   - 좌표: `가로칸`, `세로칸`(숫자지만 격자 위치라 평균은 의미 없음)
   - `불량사유`, `등급`은 기준표로 계산되는 결과 열이므로 입력 변수가 아니라 목표 변수로 다룬다.

6. **저장.** 요약은 `docs/사과_요약.md`로, 교차표는 `docs/사과_불량사유_위치별.xlsx`(시트 `불량사유_위치별`)로 저장한다. 사용자가 요청한 것만 저장하고, 저장 경로를 답변에 적는다.

## 답변 방식

- 숫자는 스크립트 출력을 그대로 쓴다. 기억에서 옮기지 않는다.
- 위치별 차이의 원인은 이 파일만으로 알 수 없으므로 단정하지 않는다. 교차표에서 보이는 사실(예: 가장자리에서 무게 미달·당도 미달이 많음)만 말한다.
- 직접 만든 `.xlsx`는 엑셀 프로그램에서 열어 보지 못했다는 점을 밝힌다.
- 날짜가 다른 파일(`apple_A25.xlsx` 등)도 같은 방식으로 처리한다. 기준표 검증 문구는 `A07`에만 있지만 재판정은 모든 파일에 실행해 본다.
